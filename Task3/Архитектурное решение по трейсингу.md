**Трейсингом нужно покрыть**:

1. MES API
2. CRM API

На диаграмме в каталоге Task3 указаны элементы системы, которые предлагается покрыть трейсингом.

**Набор данных для трейсинга**:

1. Идентификатор заказа
2. Идентификатор модели
3. Источник/инициатор заказа
4. Текущий статус заказа

**Мотивация**

Внедрение трейсинга повлияет на:

1. Измерение количества запросов от разных источников (бизнес-метрика)
2. Измерение количества запросов от разных источников и их статуса (бизнес-метрика). Позволяет отследить потенциальные проблемы (например - запросы полученные от внешнего магазина обрабатываются ошибочно).
3. Анализ времени прохождения запроса через CRM API и MES API (техническая/бизнес метрика позволяют понять, на каком этапе обработки запроса возникла задержка)

**Предлагаемое решение**

OpenTelemetry для сбора телеметрии + Jaeger для визуализации трассировок. Доступ к UI должен быть только у сотрудников компании с актуальной учетной записью и ролью “Поддержка”».

**Компромиссы**

В идеале также покрыть трейсингом апи онлайн магазина и хранилище 3d моделей. Hо так как описанные в задаче проблемы в первую очередь находятся в других АПИ, то онлайн магазин и хранилище в трейсинг можно добавить позже, при необходимости.
